| 认识键盘教学设计 |  |  |  |  |
| --- | --- | --- | --- | --- |
| 教学目标 |  |  |  |  |
| 1. 能说出主键盘区、功能键区、编辑键区、小键盘区、指示灯区的名称，在实物键盘上指认其位置，并初步说明主要用途。<br>2. 能在主键盘区找到所需的字母键和数字键并正确输入，尝试完成至少一张色卡，逐步熟悉按键位置。<br>3. 能根据全班反馈发现并修正分区判断，在自主练习与同伴交流中保持正确坐姿、规范操作和爱护设备的习惯。 |  |  |  |  |
| 教学重难点 |  |  |  |  |
| 重点：认识键盘五个区域的位置、范围和主要用途，使用主键盘区输入字母和数字。<br>难点：区分主键盘区、小键盘区中的数字键及其他区域边界；根据目标字符找到相应按键，并在反馈后修正自己的判断。 |  |  |  |  |
| 教学准备 |  |  |  |  |
| 多媒体机房、学生电脑及标准键盘、教学课件；键盘填色与色卡打字两套独立网页及各自教师看板。<br>课前检查网页访问与反馈同步；教师在看板中新建课堂，分发学生链接。学生直接进入，无需填写姓名或座位号。课时为1课时，共40分钟。 |  |  |  |  |
| 教学过程 |  |  |  |  |
| 教学环节 |  | 学习活动 | 效果评价 | 教学创意 |
| （一）复习导入，引出键盘<br>0—2分钟 |  | 1. 教师提问：“前面的课上，我们学习了鼠标的五种用法：指向、拖动、单击、双击、右击，谁还记得分别是怎么用的？”学生简短回顾，教师依据已学内容补充。<br>2. 追问：“如果想在电脑上输入字母和数字，我们还可以请哪位好帮手？”学生回答后，引出键盘。<br>3. 揭示课题：键盘也是电脑重要的输入设备，今天一起来认识键盘。 | 能回忆鼠标五种用法（指向、拖动、单击、双击、右击），知道键盘也是输入设备，明确本课学习对象。 | 复习迁移；实物观察。 |
| 阶段<br>意图 | 从熟悉的鼠标过渡到键盘，建立新旧知识联系，简短导入后尽快进入动手活动。 |  |  |  |
| （二）明确任务，学习操作<br>2—3分钟 |  | 1. 告知键盘分为五个区域，出示颜色图例：主键盘区红色、功能键区黄色、编辑键区蓝色、小键盘区绿色、指示灯区紫色。<br>2. 示范选颜色、单击填色（也可按住拖动连续涂色）、换色修改的方法，暂不公布正确分区。<br>3. 布置任务：“看看网页上的键盘，也看看面前的键盘，按自己的判断试着填色。” | 能找到颜色图例，理解填色任务，会选择颜色和修改。 | 颜色图例常驻；操作示范。 |
| 阶段<br>意图 | 给出清楚的操作规则，保留学生独立判断区域边界的空间，为第一次尝试做好准备。 |  |  |  |
| （三）自主尝试，键盘填色<br>3—13分钟 |  | 1. 学生对照实物键盘，自主给模拟键盘各格填色；页面自动同步当前选择。<br>2. 教师巡视，帮助解决操作困难，观察学生判断分区的依据。遇到询问，先引导：“看看它的位置和周围的键，按自己的想法试一试。”<br>3. 教师查看混色键盘，悬停格子了解各颜色人数和比例，选取易混淆位置作为讲解切入点。结束前保存讲解前快照。 | 能独立作出分区判断并操作网页；教师通过填色结果识别共性困惑，不以第一次结果判定最终掌握情况。 | 先学后教；实时混色反馈。 |
| 阶段<br>意图 | 让学生先尝试、暴露真实认识，教师根据全班选择组织后续讲解，使反馈服务于教学。 |  |  |  |
| （四）查看反馈，认识五区<br>13—16分钟 |  | 1. 简看混色结果：“这些地方颜色不同，说明大家对划分还有不同想法。”切换标准分区图，反馈与讲解合计控制在3分钟。<br>2. 逐区指认并简讲：主键盘区在中间较大区域，用于输入字母、数字等；功能键区在上方，提供功能操作；编辑键区用于移动光标、翻页和编辑；小键盘区通常在最右侧，便于集中输入数字；指示灯区显示键盘状态。学生同步在实物上找一找。 | 能对照分区图找到五个区域，初步说出用途。 | 以错促学；图物对照。 |
| 阶段<br>意图 | 用简短集中讲解建立正确分区认识，回应自主尝试中的困惑，把主要时间留给学生操作。 |  |  |  |
| （五）修改填色，巩固认识<br>16—19分钟 |  | 1. 学生根据讲解修正自己的填色，继续将屏幕区域与实物键盘对应。教师对仍有混淆的学生个别指导。<br>2. 完成较快的学生与同伴互相指认：“请指出主键盘区。”“哪个区域用灯显示状态？”<br>3. 教师保存修正后快照，简短对比前后颜色变化，追问相应区域名称和修改依据。 | 能修正错误分区并说明理由；通过前后结果和实物指认检查认识是否得到巩固。 | 二次尝试；前后对比；同伴指认。 |
| 阶段<br>意图 | 把听到的讲解转化为实际修正，通过比较和指认确认理解，而不只是照图换色。 |  |  |  |
| （六）示范玩法，进入打字<br>19—21分钟 |  | 1. 打开独立打字网页，请学生找到主键盘区，提醒坐姿和轻按键盘。<br>2. 教师示范：“看准绿色目标字符，直接按键。每正确输入一次，点亮一格；输错可以重试，已点亮的颜色保留。”学生无需点击输入框。<br>3. 说明首关12格、第二关20格、后续每关30格，集满后收藏色卡并自动进入下一关。字母大小写均可，不展开大小写转换教学。 | 能理解直接按键和点亮色卡的规则，找到主键盘区，顺利开始练习。 | 一次示范；低门槛起步。 |
| 阶段<br>意图 | 用简明示范完成活动转换，让学生把注意力放在找键与输入上，尽快体验第一次成功。 |  |  |  |
| （七）打字闯关，收集色卡<br>21—37分钟 |  | 1. 学生按自己的速度练习：先输入字母，再输入主键盘区数字，随后进行简单字母、数字组合。每关收集一种色系的色卡。<br>2. 教师巡视，指导找键困难的学生，允许进度较快的学生继续挑战；以找准按键、正确输入为主，不要求统一闯关进度。<br>3. 查看教师端的最高关卡、平均关卡和分层进度，判断是否需要共性提醒或个别帮助，尽量保持练习连续。<br>4. 结束前一分钟提醒学生完成当前小组任务，查看已收集的色卡。 | 能在主键盘区正确输入字母和数字，逐渐熟悉位置；争取完成至少首张色卡。结合实际输入与看板进度给予过程评价。 | 色卡激励；分层练习；进度反馈。 |
| 阶段<br>意图 | 提供16分钟连续练习，以色卡收集保持参与兴趣，让不同基础的学生都能按自己的节奏积累输入经验。 |  |  |  |
| （八）交流收获，回顾总结<br>37—40分钟 |  | 1. 学生停下操作，简短回答：“键盘可以分成哪五个区域？”“今天输入字母和数字主要使用了哪里？”<br>2. 总结：今天认识了键盘五区，并用主键盘区输入字母和数字；继续练习会更熟悉按键位置。 | 能说出五区名称及主键盘区用途。结合指认和输入表现检查目标达成。 | 口头回顾；结合操作评价。 |
| 阶段<br>意图 | 回扣学习目标，帮助学生把区域认识与输入体验联系起来，并形成继续练习的意愿。 |  |  |  |
| 作业<br>设计 | 【基础性作业】在纸上画出键盘五个区域的简图并标注名称，向家人介绍主键盘区的用途。<br>【拓展性作业】条件允许时，输入几组字母和数字，留意一个容易找错的键，下节课与同学交流。 |  |  |  |
