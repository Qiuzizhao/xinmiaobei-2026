# 2026 新苗杯公开课：认识键盘

面向小学三年级的信息科技公开课，暂按 40 分钟设计。以学生自主尝试和练习为主，集中讲解键盘五区约 3 分钟。

打开根目录的 `index.html`，即可进入两套活动的学生端、教师端，或查看《认识键盘》教学流程文档。

在线入口：[GitHub Pages](https://qiuzizhao.github.io/xinmiaobei-keyboard-lesson-2026/)。页面由 GitHub Pages 托管，互动数据继续使用各自独立的 QForm 任务。

## 教学流程

| 时间 | 环节 | 内容 |
| --- | --- | --- |
| 0—2 分钟 | 复习导入 | 回顾鼠标五种用法：指向、拖动、单击、双击、右击，引出另一个输入设备——键盘。 |
| 2—3 分钟 | 填色任务说明 | 介绍五区名称、颜色规则和网页操作，暂不揭示分区边界。 |
| 3—13 分钟 | 自主填色 | 学生对照实物键盘尝试填色，教师查看全班混色结果。 |
| 13—16 分钟 | 反馈与讲解 | 结合结果，讲清五区的位置、范围和主要功能。 |
| 16—19 分钟 | 修正与巩固 | 修改填色，对照实物键盘指认区域。 |
| 19—21 分钟 | 打字任务说明 | 示范使用主键盘区输入字母、数字，说明色卡闯关规则。 |
| 21—37 分钟 | 打字闯关 | 正确输入字符，点亮色卡，按个人进度继续练习。 |
| 37—40 分钟 | 回顾总结 | 回顾五区和主键盘用途。 |

五区为主键盘区、功能键区、编辑键区、小键盘区、指示灯区。具体边界与教材及课堂实物键盘一致。本课不展开双字符键、控制键和大小写转换教学。

## 网页需求

### 键盘填色

- 独立学生端和教师端，使用独立的 QForm 任务。
- 学生端选择颜色后对模拟键盘填色，可修改，自动上传当前状态。
- 当前填色通过 QForm 实时状态通道覆盖更新，讲解前后成果可通过正式提交保留。
- 教师端读取全班当前状态，按键位显示颜色分布。
- 鼠标悬停某个键或指示灯格子时，提示各颜色人数及百分比，未填色单独统计。
- 课堂编号和自动生成的匿名设备标识用于隔离数据；学生无需填写姓名或座位号。短暂离线保留最后的填色。

### 打字点亮色卡

- 与填色活动完全独立，拥有自己的学生端、教师端和 QForm 任务。
- 正确输入一个目标字母或数字，点亮一个颜色方格；输错可重试，保留已点亮进度。
- 每关一种色系，格子呈现不同深浅的颜色；集满后收藏色卡并进入下一关。
- 第一关暂定 12 格，后续逐步增加到 20 格、30 格左右。
- 练习由字母、数字过渡到简单组合，使用主键盘区，不考查大小写转换。
- 学生端仅上传累计正确输入数量、当前关卡及必要的学生标识和更新时间。
- 教师端展示参与人数、最高关卡、平均关卡，以及前 10%、25%、50%、75% 学生至少达到的关卡。

## 互动网页第一版

两套活动独立运行、独立 QForm 任务。学生直接进入，匿名设备标识自动生成；同一浏览器刷新可续练。

| 活动 | 学生端 | 教师端 |
| --- | --- | --- |
| 填色盘 | [填色](https://qiuform.qiuzizhao.com/p/urw467xtz4n7/student.html) | [混色看板](https://qiuform.qiuzizhao.com/p/urw467xtz4n7/teacher.html) |
| 收集色卡 | [打字](https://qiuform.qiuzizhao.com/p/cujbj48aycbw/student.html) | [进度看板](https://qiuform.qiuzizhao.com/p/cujbj48aycbw/teacher.html) |

使用步骤：教师打开对应看板，点击“新建课堂”，复制该课堂的学生链接后分发。两套活动分别分发自己的链接，不联动切换。

教师端通过下拉列表直接切换课堂，无需输入编号。新课堂自动生成六位简短编号，列表显示北京时间的创建日期和时间。课堂信息永久保存在各自 QForm 任务中，GitHub Pages 与 QForm 教师端共用列表；旧课堂仍可进入，未记录过创建时间的显示“创建时间未记录”。

填色看板支持悬停/点击键位查看颜色人数与比例、标准分区，以及保存并回看讲解前后全班快照。学生可点击或按住鼠标连续涂色。

打字页面打开后即可直接按键，无需点击输入框；点击页面其他位置也可继续练习。每次正确输入点亮一格，首关 12 格、第二关 20 格、后续 30 格。兼容字母大小写，中文输入法接管按键时根据物理按键识别；错误输入不增加进度，不扣已有进度；数字练习提示使用主键盘。忽略快捷键和长按重复，禁用粘贴跳关。

教师看板支持本机示例模式：给网址加 `?demo=1`，点击“生成示例学生”。示例不上传 QForm；通过普通学生链接进入才使用真实接口。

### 本地修改与预览

```text
npm run build
npm start
```

打开 `http://127.0.0.1:18080/`。`web/src/` 为可维护源码，`web/config.json` 保存两个独立任务编号；构建生成四份自包含 HTML，可直接分别上传到对应 QForm 任务。两套发布网页不依赖彼此的文件。

```text
npm test
```

验证色卡关卡边界、百分位统计、混色计数、练习字符和 QForm 状态包装格式。

### 数据约定

- 填色任务：`urw467xtz4n7`；打字任务：`cujbj48aycbw`。
- `PUT /api/<任务编号>/state/<活动>:<课堂>:<匿名设备>?ttl=7200` 保存最新状态，有修改时填色约每 5—6 秒、打字约每 10—11 秒合并上传；无修改时约每 60—70 秒刷新在线时间。
- `GET /api/<任务编号>/state` 由教师端约每 5—6 秒读取。按课堂编号与活动筛选，不把历史课堂混入当前统计。
- 填色教师端通过 `POST /api/<任务编号>` 保存全班快照，`GET /api/<任务编号>/all` 恢复历史快照。
- 打字仅上传累计正确输入数、当前关卡、匿名标识及更新时间，不保存逐键记录。
- 教师新建课堂时通过 `POST /api/<任务编号>` 保存一条 `type: classroom` 的创建记录；教师端通过 `/all` 读取课堂列表，定期更新并合并当前在线的旧课堂。课堂记录不随实时进度过期。
- 实时状态 2 小时未更新后自动过期；永久对比以教师保存的快照为准。
- QForm 为公开读写任务接口；只收匿名学习进度。任务编号不是管理凭据，网页不包含账号密码。

已完成关键功能本地浏览器检查和 QForm 线上双端同步检查。尚未验证学校机房多人同时使用时的网络表现。正式教案和课件尚未制作。

### 请求节流与性能

学生只上传最新状态，不逐键上传；过关不会额外强制上传。后台页面和离线状态暂停网络请求，重新回到页面后错峰恢复。上传与轮询各自避免并发，失败后逐步延长重试间隔；遇到 429 至少等待 60 秒，并遵守服务器的 Retry-After。

教师端课堂记录每 3 分钟刷新，课堂列表与快照共用 60 秒读取缓存并合并同时请求。看板数据没有实质变化时跳过重复绘制，在线状态仍定期刷新。学生填色和打字不等待服务器响应，网络恢复后继续上传最新进度。

键盘分区按课堂参考图：顶部 Esc、F1—F12、Print Screen、Scroll Lock、Pause/Break 均归功能键区；编辑键区只包含 Insert、Home、Page Up、Delete、End、Page Down 和四个方向键。三盏状态指示灯与小键盘区分开统计。

### QForm 课堂负载测试

2026 年 10 月 26 日完成分阶段实测：两套分别模拟 10、25、40 名学生，教师端同时查询。共 1053 次请求全部成功，未发生 429、超时或请求失败；最高阶段 40+40 人持续 60 秒，平均 12.4 次请求/秒，95% 耗时 71.2 毫秒。此结果覆盖本次短时课堂负载，不代表服务器极限或整节课持续表现。

查看 [完整报告](docs/qform-load-test.html) 和 [原始统计](docs/qform-load-test.json)。需要重新测试时，显式执行 node tests/qform-load.cjs；常规 npm test 不会向 QForm 发起压测请求。
